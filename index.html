The problem

The places that need warnings most are often the hardest to connect.

Remote farmers, forest-edge communities, tribal communities, and isolated settlements often have unreliable or nonexistent cellular and internet connectivity. Conventional connected systems quietly assume a chain that simply doesn't exist there.

Architecture

How NETRA works

Four physical layers, each one doing exactly one job — none of them dependent on a network reaching the site.

01 / Sensor Node

Reads the environment, on-site

A weatherproof node placed in the field measures temperature and humidity continuously, running on battery with solar charging.

ESP32SX1278 Ra-02 LoRaDHT22Battery + solarWeatherproof enclosure
02 / LoRa Communication

Long-range, low-power, no network

Sensor nodes reach the gateway directly over LoRa radio — no SIM, no Wi-Fi, no Internet, no cell tower anywhere in the path. Open-field range is still being validated in our own testing; we don't quote a fixed number until it's verified in the actual deployment environment.

Long-rangeLow-powerNo SIMNo Wi-FiNo Internet
03 / Gateway

The local intelligence unit

Installed at the farmhouse or outpost, the gateway receives every sensor reading and decides, entirely on its own, whether it's dangerous.

ESP32LoRaLCDRTCSD storageRGB LEDBuzzerDFPlayer Mini
04 / Local Intelligence

Threshold logic today, trend prediction next

The current prototype evaluates each reading against fixed thresholds — temperature ≤2°C triggers a frost alert, ≥42°C a fire alert, 30–42°C a heat watch. A lightweight rate-of-change trend calculation is planned next, to warn before a threshold is even crossed. This is deliberately not a trained AI/ML model at this stage.

Offline evidence

When something happens, remember it.

Every alert is timestamped locally — using an onboard real-time clock that keeps ticking with no power and no network — and written to an SD card, building a durable, tamper-evident record of what happened, and when.

This can help a farmer document an incident for later verification, including insurance-related processes. It does not, on its own, guarantee that any claim will be approved.

Accessibility

A planned DFPlayer Mini module can play short, pre-recorded local-language warnings through a speaker — for anyone who might not read English text on a screen, especially at night.
